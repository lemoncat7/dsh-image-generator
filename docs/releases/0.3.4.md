# 0.3.4 · 桌面端设置保存与测试修复

- 修复 DSH 桌面端转发请求时移除 `Origin`、`sec-fetch-site`，导致插件保存设置和测试连接返回 403 的兼容问题。
- 设置页写请求携带插件专用非简单请求头；仅在来源元信息缺失、连接来自本机且 Host 为回环地址时启用兼容分支。不信任代理来源头，不开放跨站 CORS；宿主继续负责认证。
- 保留普通 Web 同源校验，拒绝显式跨站来源、来源冲突、非本机连接及缺少专用头的无 Origin 写请求。
- 前后端必须一起更新，更新后重新加载设置页。无需修改 DSH 核心源码，不修改 API Key、模型或服务地址。

验证：8 项回归测试通过；使用 DSH 桌面端实际 `forwardWebRequest` 源码转发到本地 HTTP 服务，读取、保存、测试均为 200，外站 Origin 为 403。上游模型接口使用测试桩，没有调用付费生图；此验证不等同于在用户 Mac 上运行完整桌面客户端。
