# 生图 0.3.5

## 宿主兼容

本版本明确支持 **DeepSeek Harness 0.2.1-rc.2**。包的 `engines.dsh` 与相关运行时 peerDependencies 已更新为 `^0.2.1-rc.2`，构建依赖固定为本次验证版本。其他宿主版本未由本次验证覆盖。

仍在 DSH 0.2.0-rc.2 的用户请继续使用 **0.3.4**，不要在旧宿主上强制安装本版。

## 更新

- 更新 DSH 依赖及安装兼容声明，明确支持 0.2.1-rc.2，解除只能安装在旧版精确宿主上的限制。
- 保留图像生成工具、模型配置和设置页面。

## 验证与升级

已验证隔离与正式宿主设置页面、配置读取及重启持久化；未执行收费图像生成测试。

安装：`dsh plugin --profile web add @lemoncat7/dsh-image-generator@0.3.5`。

请先备份配置与插件数据，升级到上述宿主后再安装本版，并重启实际使用的 Profile（桌面端按其 Profile 操作）。本次不修改 DSH 核心源码，不清理或迁移生产会话数据。

详见 [DSH 0.2.1-rc.2 兼容说明](../dsh-021-compatibility.md)。
